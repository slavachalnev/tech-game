# Referee's secret notes for this game

Hidden from the player: the view never shows this file. Keep it short and current.

## Fixed facts

## Hidden state
What's happening out of the player's sight: rivals' progress, people's private plans and grudges, slow processes (wear, water, rumours).

## Planned events
